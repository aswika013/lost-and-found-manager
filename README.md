# Lost and Found Management System

This project is a Lost and Found Management System that I am developing as part of my learning in backend development.

I am still a beginner with Java and Spring Boot, so I am building this project while learning the technologies involved. I also plan to document the steps I take during development, including the setup, implementation, problems I face, and how I solve them.

## Project Setup

Since I was starting from the basics, I first had to set up the development environment.

I installed:

* Java
* Maven
* Spring Boot
* VS Code
* WSL
* Ubuntu

I made sure that the versions of Java, Maven, and Spring Boot were compatible with each other before starting the project.

I then set up WSL and Ubuntu as my development environment and connected VS Code to it.

After that, I connected my development environment to GitHub through the Ubuntu environment and linked the project to a GitHub repository. This also helped me start getting familiar with Git and GitHub while working on the project.

## About the Development

The main purpose of this project is to build a system where users can report and manage lost and found items.

Some of the features I plan to implement are:

* Adding lost items
* Adding found items
* Viewing reported items
* Searching for items
* Managing the status of an item
* Matching lost and found items

The features may change as I continue developing the project.
